# AWS Media Pipeline

Serverless image-optimization pipeline on AWS — drop an image, get WebP/AVIF
variants back in seconds, generated by a Lambda pipeline you can watch work.
Built as Level 06 of [jabordones.com](https://www.jabordones.com).

**Status:** under active development. This README is a scaffold; the full
architecture diagram, design decisions, and cost breakdown land once the
stack is deployed and verified end-to-end.

See `prompt-project-aws-media-pipeline.md` for the original spec.
