## 4. Code-change request: `allow-downloads` on the iframe sandbox

`src/app/projects/[slug]/CaseStudy.tsx` currently sets:

```
sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-popups-to-escape-sandbox"
```

Please add `allow-downloads` to that list. Without it, the download links
in this tool's results table are silently blocked when embedded (this repo
already sets `Content-Disposition: attachment` on every generated variant
and uses `target="_blank"` on the links specifically to work around this,
but `allow-downloads` is still needed for the embedded case to actually
trigger a save rather than navigate).

## 5. Architecture diagram — not wired up, by design

`docs/architecture.svg` in this repo is a clean, flat reference diagram of
the pipeline (flow, not literal AWS icons). Chu-Website has **no existing
support for rendering a diagram in a case study** — no field on `Project`,
no slot in `CaseStudy.tsx`. Wiring it in would mean adding something like
an `architectureDiagram?: string` field plus a new section in
`CaseStudy.tsx` that re-renders it in the site's own flat, no-shadow style
(ámbar/`secondary`, since Projects is that zone). That's a real code
change with its own design decisions, so it's called out here rather than
silently bundled in — happy to help with it as a separate task if wanted.
